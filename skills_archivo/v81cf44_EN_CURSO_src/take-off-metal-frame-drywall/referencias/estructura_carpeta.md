```

├── 00_INDICE_DE_ARCHIVOS.md        qué es cada archivo
├── Excel\                          el take-off
├── Planos marcados por tipo\       el juego completo de hojas
├── Documentos\                     cierres, auditoría, protocolo vigente
└── Herramientas\                   los scripts que lo producen y lo verifican
```

## Una sola versión vigente, no una pila de versiones

El protocolo se guarda como **`SKILL_take-off_VIGENTE.md`** — nombre fijo, se **reemplaza** cada vez. Acumular `v25, v26, v27…` en la misma carpeta obliga a adivinar cuál rige, que es la misma enfermedad que las tres copias del Excel en `Claude outputs`.

Las adendas fechadas siguen existiendo como registro de **por qué** se agregó cada regla, pero el archivo que se lee para trabajar es uno solo.
