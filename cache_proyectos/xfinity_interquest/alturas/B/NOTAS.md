# Reader H-B - height notes (clean bid set only)

Sources used: bidset_SIN_MARKUPS.pdf (A0.1, A1.0, A2.0, A3.0, A4.0, A5.0), set_texto.json, MAPA_A1.0/A2.0/A3.0 (location only).

## Rules applied
- "X above ceiling" -> HIGHER ceiling of the two sides + printed extension (0'-6").
- Extension 0'-6" printed in 3 places on A2.0 (all agree): Wall Type 2 "FROM SLAB TO 6" ABOVE CEILING U.N.O.", Wall Legend "FULL HEIGHT PARTITION TO 6" ABOVE CEILING U.N.O.", detail 4/A2.0 "6" TYP" above suspended ceiling. Key note 1 (columns) "TO 6" ABOVE CEILING".
- Conflicting printed values -> the higher one. No conflict was found between A3.0, A4.0 and A5.0 ceiling heights.

## Per element
- W2-01: wall between Storage 101 (10'-0" ACT) and Retail 100 (12'-0" ACT); includes the door 101 zone. 12'-0" + 0'-6" = 12.5 ft. Alternative (lower side only, Storage): 10.5 ft - rejected by the higher-side rule.
- W2-02: wall between Hallway 102 (existing gyp bd 9'-0") and Retail 100 (12'-0"). 12.5 ft. Alternative (Hallway side board only to 9'-6" = 9.5 ft) if each face were cut at its own ceiling + 6"; not used (rule = higher side for the wall).
- Detail 4/A2.0 shows studs stopping 6" above the ceiling with diagonal braces "TO STRUCTURE" (max 25'-0" brace, studs @ 8'-0" O.C.). The braces are not board; their length is not a wall height and the structure height is not printed.
- CF-01 / CF-02: columns on the storefront line inside Retail 100 (tag 5/A2.0 SIM.). Only the Retail side, 12'-0" + 0'-6" = 12.5 ft. Detail 5/A2.0 prints no height. A1.0 key note 13 "EXISTING STOREFRONT BULKHEAD ABOVE" is near these columns, but no bulkhead height is printed anywhere, so it was not used.
- DEMO-01..11: A1.0 key note 7 (dashed interior walls to be removed). No height of the existing walls, existing ceiling or structure/deck is printed on any sheet (A1.0 note 14 "NO STRUCTURAL ELEMENTS ARE INCLUDED IN THIS SCOPE OF WORK"; the E/M/P SHX text was searched for deck/joist/structure/B.O. heights and has none). Rule U-174 -> A0.1 "HEIGHT IN STORIES: 1 STORY - 26 FT" = 26.0 ft. Note: 26 FT is the building height, not a measured clear height to structure; real demo walls are likely lower (for example, only to an existing ceiling). There is no printed value to support a lower number, so field verify.
- SOF-01: gyp bd header "GYP. BD. 8'-6" AFF" at the end of Hallway 102 next to Storage 101.
  - Storage face: 10'-0" + 0'-6" - 8'-6" = 2.000 ft
  - Hallway face: 9'-0" + 0'-6" - 8'-6" = 1.000 ft
  - Underside: no printed dimension; measured on A3.0 vectors at 1/4" = 1'-0" (18 pt/ft): horizontal lines at y = 1618.20 pt and y = 1625.52 pt (visible coordinates, x 846.84 to 923.28). (1625.52 - 1618.20) / 18 = 0.407 ft (about 4 7/8")
  - Developed total = 3.407 ft. The header length along the hallway (x 846.84 to 923.28 = 76.44 pt = 4.247 ft) is length, not height. It is shown only for reference, and the A2.0 hallway width dimension 4'-3 1/8" (4.260 ft) is close to it.
  - Alternative: if the Storage face were taken only to the Storage ceiling (no extension), the face would be 1.5, giving a total of 2.907 ft. Not used.
